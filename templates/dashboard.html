What this system does

It applies {{ stats.rule_count }} transparent, configurable rules to historical retail transactions and shows why each flagged record was flagged: the observed value, the threshold, and the rule that produced it.

There is no machine learning here, and no record is described as fraud. The output is a prioritised list of transactions that may deserve manual review.
